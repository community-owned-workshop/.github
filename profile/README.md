# COW - Community Owned Workshop

The goal of the COW Initiative is:

> _"Keep mods alive without splitting them into countless competing versions."_

## Idea

COW gives each mod one shared home:

- one repository
- one workshop item
- one community that can maintain it together

### Advantages For Players

- One canonical version to find and subscribe to.
- Fewer abandoned or incompatible forks.
- Mods can survive inactive maintainers.

### Advantages For Mod Authors

- Share the maintenance workload.
- Step away without abandoning the mod.
- Keep the project's history and identity intact.
- Share knowledge by sharing code.

### Advantages For Contributors

- Improve the original mod instead of creating another fork.
- Use shared tests, reviews, and publishing tools.
- Turn accepted contributions directly into workshop updates.
